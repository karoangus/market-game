# 🛒 سوپرمارکت من — بازی سه‌بعدی مدیریت سوپرمارکت

بازی مدیریت سوپرمارکت **سه‌بعدی** و **موبایل** (Three.js + JavaScript خالص، بدون build step).
بازیکن با **۱۰۰ دلار** و یک سوپرمارکت **۲۰ متری (۵×۴ متر)** شروع می‌کند.

## 🎮 حلقهٔ روزانه (نسخهٔ فعلی)

```
قیمت بازار مشخص شود → خرید جنس → چیدن روی قفسه → قیمت‌گذاری →
ورود مشتری‌ها → فروش → محاسبهٔ سود → روز بعد (قیمت‌ها تغییر می‌کنند)
```

- **۵ محصول:** نان، سیب، موز، روغن، برنج
- **نوسان قیمت روزانه:** هر روز قیمت خرید، با «بلندای تصادفی محدود» داخل محدودهٔ
  هر محصول تغییر می‌کند (تصادفی ولی منطقی — پرش‌های عجیب ندارد و به‌آرامی به
  قیمت پایه برمی‌گردد):

| محصول | قیمت پایه | حداقل | حداکثر |
|---|---|---|---|
| 🍞 نان | ۴ | — فعلاً ثابت | — |
| 🍎 سیب | ۱۰ | ۵ | ۲۰ |
| 🍌 موز | ۱۳ | ۷ | ۱۷ |
| 🛢️ روغن | ۱۷ | ۱۰ | ۲۰ |
| 🍚 برنج | ۲۰ | ۱۵ | ۳۰ |

  قیمت نان فعلاً قابل تنظیم است (مقدار آن در `js/config.js` قابل تغییر است) و
  سیستم نوسان آن آماده است؛ کافی است `fluctuates: true` شود.

- **قیمت‌گذاری بازیکن:** قیمت فروش هر محصول کاملاً آزادی (۱ تا ۱۰۰ دلار).
  رفتار مشتری تابع اختلاف قیمت فروش از بازار است:
  - تا ۲ دلار بالاتر: فروش خوب
  - **۳ تا ۴ دلار بالاتر: تمایل خیلی کم یا اصلاً خرید نمی‌کنند**
  - بالاتر: خرید = صفر
- **مشتری‌ها** در صحنهٔ سه‌بعدی وارد می‌شوند، به قفسه می‌روند، خرید می‌کنند،
  صندوق می‌دهند و می‌روند (اگر موجودی نباشد یا گران باشد، دست‌خالی برمی‌گردند).
- **ذخیره‌سازی خودکار** در `localStorage` — «ادامهٔ بازی» همیشه موجود است.

## 🚫 عمداً در این نسخه نیست (برای آپدیت‌های آینده)

توسعهٔ فروشگاه، استخدام کارمند، شعبه‌های جدید، تبلیغات، دزدی، انبار بزرگ،
اقتصاد پیچیده‌تر و محصولات بیشتر — همه برای آپدیت‌های بعدی نگه داشته شده‌اند و
ساختار کد برای آن‌ها آماده است (بخش بعدی).

## 🏗️ ساختار کد (طراحی‌شده برای گسترش آسان)

```
index.html          پوستهٔ بازی + همهٔ رابط‌های DOM
css/style.css       استایل موبایل (RTL)
js/
  config.js         📦 کاتالوگ محصولات + تنظیمات کل بازی
  economy.js        📈 نوسان قیمت بازار + تابع رفتار مشتری
  state.js          💾 وضعیت بازی + ذخیره/بارگذاری (سازگار با محصولات آینده)
  scene3d.js        🏬 دنیای سه‌بعدی: اتاق، قفسه‌ها، مدل‌ها، تگ قیمت
  customers.js      🚶 شبیه‌سازی روز و رفتار مشتری‌ها
  ui.js             🖥️ HUD و پنل‌های تأمین‌کننده / قیمت‌گذاری / گزارش
  sound.js          🔊 افکت‌های صوتی WebAudio (بدون فایل)
  main.js           🎮 نقطهٔ ورود و حلقهٔ بازی
test/economy.test.mjs  ✅ تست‌های منطق اقتصاد
```

### ➕ افزودن محصول جدید
فقط یک ردیف به `PRODUCTS` در `js/config.js` اضافه کن:

```js
{
  id: 'milk', name: 'شیر', emoji: '🥛', color: 0xffffff,
  basePrice: 12, priceRange: { min: 8, max: 18 }, fluctuates: true,
}
```

بیشتر کارها خودکار است: قفسهٔ ششم (جایگاه آزاد در `SLOTS`)، پنل‌های
تأمین‌کننده و قیمت‌گذاری، مشتری‌ها و ذخیره‌سازی قدیمی. برای مدل سه‌بعدی
اختصاصی، یک تابع به `BUILDERS` در `js/scene3d.js` اضافه کن (وگرنه مدل
جعبه‌ای پیش‌فرض ساخته می‌شود).

### ➕ تغییر محدودهٔ قیمت‌ها / کالیبره‌کردن اقتصاد
- محدوده‌ها: `priceRange` هر محصول در `config.js`
- شدت نوسان روزانه و کشش به قیمت پایه: `economy.js → rollMarketPrices`
- حساسیت مشتری به قیمت: `economy.js → buyChance`

### ➕ افزودن سیستم جدید (کارمند، انبار، شعبه، تبلیغات…)
سیستم‌ها روی `state` کار می‌کنند؛ ماژول جدید در `js/` بساز، فیلدهایش را در
`state.js` تعریف کن (بارگذاری ذخیرهٔ قدیمی سازگار است) و در `main.js` به
حلقهٔ بازی وصلش کن. قفسه‌های اضافه در `SLOTS` و محل‌های جدید در صحنه در
`scene3d.js` جای رشد آینده را رزرو کرده‌اند.

## ▶️ اجرا در لوکال

هر سرور استاتیک کافی است:

```bash
python3 -m http.server 8080
# یا
npx serve .
```

سپس `http://localhost:8080` را (ترجیحاً در حالت موبایل مرورگر) باز کن.

## 📱 PWA (وب‌اپ قابل نصب)

بازی یک **PWA کامل** است — روی موبایل از مرورگر «افزودن به صفحهٔ اصلی» را بزن:

- `manifest.webmanifest` + آیکون‌های ۱۹۲ و ۵۱۲ (`icons/`)
- `vendor/three/`: موتور سه‌بعدی three.js به‌صورت محلی داخل پروژه (بدون نیاز به CDN)
- `sw.js`: Service Worker با cache-first برای پوستهٔ اپ و stale-while-revalidate
  برای فونت وب — بعد از اولین بارگذاری، بازی **آفلاین** هم کار می‌کند.
- نمایش standalone (تمام‌صفحه، بدون نوار مرورگر) و رنگ theme.

> هنگام تغییر فایل‌های اپ، `VERSION` در `sw.js` را تغییر بده.
